# More room for my hand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A two-row, larger, tappable hand on portrait phones, a wider fan in landscape, and a pill that never covers the cards.

**Architecture:** `handLayout(count)` in `static/card-physics.js`; `layoutHand(element, count)` in `app.js` sets `--hand-cols` and `data-rows` wherever a hand is filled (`fillHand`, the auction hand); the layout is CSS media queries on `.table-hand`.

**Tech Stack:** Plain browser JavaScript and CSS, Node's test runner.

**Spec:** `docs/superpowers/specs/2026-11-05-hand-room-design.md`

## Global Constraints

- Desktop and tablet (> 760 px) rendering unchanged; no new text; effects levels unaffected (no new animation).
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; PR title `feat: more room for the hand on phones (US-108)`.

## Review Focus

- The dealing animation and the hand-in animation still work in the grid.
