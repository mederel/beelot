# Tab bar (US-117) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A four-tab bar (Play, Crew, Progress, Me), at the bottom on phones and at the top from 1024px, hidden during a match, with the old top "Settings" link removed.

**Architecture:** `router.js` owns the tab list and says which tab each route belongs to; `renderView` shows or hides one `<nav>` and marks the current tab; CSS turns the same element into a bottom bar or a top navigation. The tabs are plain links that already go through `navigate()`.

**Tech Stack:** Vanilla JS plain scripts, `node --test` with `.cjs` tests in `crates/beelot-server/frontend-tests/`, CSS in `styles.css`.

**Spec:** `docs/superpowers/specs/2026-11-06-tab-bar-design.md`

## Global Constraints

- Tabs, in order: Play `/` ♠, Crew `/online/private` ♥, Progress `/stats` ♦, Me `/settings` ♣; glyphs are `aria-hidden`.
- Tab per route: `play` for `/`, `/index.html`, `/play/bot`, `/play/local`, `/tutorial`, `/rules`; `crew` for `/online/private`, `/online/public`; `progress` for `/stats`; `me` for `/settings`, `/privacy`; `null` for `/play/bot/game/:id`, `/play/bot/bidding/:id`, `/online/{private,public}/table/:id`; unknown paths are `play`.
- The nav is `<nav class="tab-bar" id="tab-bar" aria-label="Main">`, hidden when the tab is `null`, `aria-current="page"` on the current link; each tab is at least 44px high.
- New texts `Play`, `Crew`, `Progress`, `Me`, `Main` in `i18n.js` and `i18n-nl.js` (French: Jouer, Équipe, Progrès, Moi, Principale; Dutch: Spelen, Team, Voortgang, Ik, Hoofdmenu), flagged for native review in the PR.
- No Rust, API, CSP or existing-view change. Frontend tests run with `node --test crates/beelot-server/frontend-tests/*.cjs`.
- Colours from existing tokens (`--card-paper`, `--card-ink`, `--gold`); Reduced and Off effects add no motion.

## Review Focus

- A cold load of a match URL (`/play/bot/game/:id`) must show no bar (Task 2).
- `/online/public` must highlight Crew, `/privacy` must highlight Me (Task 1).
- The last button of each tab view must not sit under the bottom bar at 375×667 (Task 3).
- An unknown path shows the bar with Play highlighted (Task 1).
- Leaving a match returns the bar without a reload (Task 2).
