# End the match with a show (US-093) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a match ends, open a full-screen cartoon takeover with a podium, the final scores, a recap (rounds, biggest round, scored announcements) and "Play again" / "Home", for every mode.

**Architecture:** `beelot-game` computes a `MatchRecap` from the rounds the match already keeps; the snapshot attaches it to `MatchView` once the match is complete. A new `static/match-end.js` has a pure model (`matchEndModel`, tested in Node) and a thin DOM part driving one shared `#match-end` overlay; `app.js` opens it after the US-090 sticker and wires "Results", "View table" and "Play again" to the existing rematch actions.

**Tech Stack:** Rust (`beelot-game`, `beelot-server`, serde), plain browser JavaScript and CSS in `crates/beelot-server/static/`, Node's built-in test runner.

**Spec:** `docs/superpowers/specs/2026-11-04-match-end-design.md`

## Global Constraints

- No new dependency, no new Settings option, no database or history change.
- `recap` is present in the match snapshot only when the match is complete (`Option`, left out of the JSON otherwise); snapshots of a match in progress and `tests/contract/*.json` do not change.
- Only the winning viewer gets the sticker and confetti; the losing viewer sees the same podium with the neutral heading `t("{0} win the match!", team)` and no confetti. The viewer's team is `board.currentPlayerIndex % 2` (0 = North–South), as in US-090.
- "Play again" is the existing rematch action `{ type: "rematch" }`; "Home" is a link to `/`.
- No score count-up: podium scores appear at once.
- Timing: the overlay opens about 2.4 s after the trick reveal for the winning viewer and about 1 s for the losing viewer; in pass-and-play it waits for the hand-off cover; on a reload (no reveal) it opens at once without confetti.
- Effects levels (US-094): Full fades in, the steps rise one after the other and confetti falls (winning viewer only); Reduced fades in within `--effect-fast`, no confetti; Off appears at once. New keyframes get their Reduced and Off rules, with selectors specific enough to beat any per-kind rule.
- The overlay is a modal dialog: focus to "Play again" on open, back to the "Results" button on close, `main` `inert` while open, confetti `aria-hidden`, Escape = "View table".
- Every new text goes through `t()` with French (`i18n.js`) and Dutch (`i18n-nl.js`) entries; no plurals (announcement counts read "Tierce ×1, Carré ×1").
- `match-end.js` must load in Node (no DOM access at top level), exporting through `if (typeof module !== "undefined")`.
- Commits are signed, one per task, ending with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; pull request title `feat: end the match with a show (US-093)`.

## Review Focus

- Announcement counts: a declared but unscored announcement is not counted, and a failed contract's announcements follow the same `scored` and seat-team rule the round result uses.
- Biggest round ties: the earliest round wins, and within one round North–South wins an equal split; a match with no round has no biggest round.
- The losing viewer, and a viewer in no team: no sticker and no confetti, neutral heading, same podium.
- A reload on a finished match opens the overlay at once; "Play again" and a re-render of an unfinished match close it and clear "dismissed", so the next match end opens it again.
- Every close path (View table, Escape, Play again, Home, leaving the table) removes `inert` from `main` and the Escape listener; a second open never leaves two overlays or two listeners.
