# Plan: the longest texts, the largest numbers and the biggest fonts (US-204)

Design: `docs/superpowers/specs/2026-11-24-extremes-design.md`.

1. **Spec and plan.** Commit the design and this plan.
2. **The language option.** `fixtures.ts` takes `language` (default `en`).
3. **The fixture and the text check.** `web/e2e/extremes.ts`: `worstCase`, `findTextFaults`.
4. **The spec.** `web/e2e/extremes.spec.ts`: the fixture, the screens in `en`, `fr` and `nl`, and the three text sizes.
5. **Run** it on the widest set of sizes; fix the CSS or exempt, with a written reason, each fault it finds.
6. **Engines.** Add the spec to the WebKit and Firefox sets of `devices.ts`.
7. **Check.** `npm run check && npm run lint && npm test`; `npm run build` and commit `static/`.
8. **Docs.** `pages/docs/develop.html` mentions the new spec.
