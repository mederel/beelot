# Play in one tap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Play now" button under the home headline starts a default bot game in one tap, above the fold on a phone.

**Architecture:** A `#play-now` button in `index.html` calls a new `startBotGame(settings)` in `app.js` (shared with the setup form) with `DEFAULT_BOT_GAME`; CSS compacts the hero under 760px.

**Tech Stack:** Plain browser JavaScript and CSS, Node's test runner.

**Spec:** `docs/superpowers/specs/2026-11-04-play-now-design.md`

## Global Constraints

- No server change, no dependency, no Settings option; new text through `t()` with FR and NL entries.
- Defaults: `{ kind: "LOCAL", difficulty: "RELAXED", variant: "CLASSIC", announcements: true, allTrumps: true, target: 1000 }`.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; PR title `feat: play in one tap from the home page (US-101)`.

## Review Focus

- Request fails (server down): the button re-enables and the error shows under it.
- Double tap: the button is disabled during the call, so one table is created.
- Effects "Off"/"Reduced": no new animation, nothing to switch off.
