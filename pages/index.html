Install on Debian or UbuntuInstaller sur Debian ou UbuntuInstalleren op Debian of Ubuntu

Current release: {{VERSION}}. On Debian 13 or Ubuntu 24.04 and later (amd64 or arm64), install it from the signed apt repository served by this site; apt upgrade then follows the releases.Version actuelle : {{VERSION}}. Sur Debian 13 ou Ubuntu 24.04 et plus récent (amd64 ou arm64), installez-la depuis le dépôt apt signé servi par ce site ; apt upgrade suit ensuite les versions.Huidige versie: {{VERSION}}. Op Debian 13 of Ubuntu 24.04 en nieuwer (amd64 of arm64) installeert u het vanuit de ondertekende apt-repository van deze site; apt upgrade volgt daarna de versies.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://mederel.github.io/beelot/beelot.asc | sudo tee /etc/apt/keyrings/beelot.asc > /dev/null
sudo tee /etc/apt/sources.list.d/beelot.sources > /dev/null <<'EOF'
Types: deb
URIs: https://mederel.github.io/beelot
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/beelot.asc
EOF
sudo apt update
sudo apt install beelot
