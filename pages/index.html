Beelot is a card game for four. Play against bots that bid and play like people, with friends at a private table, or pass one device around. Guests play every mode; an account, with a passkey, is optional.Beelot est un jeu de cartes à quatre. Jouez contre des robots qui annoncent et jouent comme des humains, avec des amis à une table privée, ou passez un seul appareil de main en main. Les invités jouent tous les modes ; un compte, avec une clé d'accès, est facultatif.Beelot is een kaartspel voor vier. Speel tegen bots die bieden en spelen als mensen, met vrienden aan een privétafel, of geef één apparaat door. Gasten spelen elke modus; een account, met een passkey, is optioneel.

On Debian 13 or Ubuntu 24.04 and later (amd64), install it from the signed apt repository served by this site; apt upgrade then follows the releases.Version actuelle : {{VERSION}}. Sur Debian 13 ou Ubuntu 24.04 et plus récent (amd64), installez-la depuis le dépôt apt signé servi par ce site ; apt upgrade suit ensuite les versions.Huidige versie: {{VERSION}}. Op Debian 13 of Ubuntu 24.04 en nieuwer (amd64) installeert u het vanuit de ondertekende apt-repository van deze site; apt upgrade volgt daarna de versies.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://mederel.github.io/beelot/beelot.asc | sudo tee /etc/apt/keyrings/beelot.asc > /dev/null
sudo tee /etc/apt/sources.list.d/beelot.sources > /dev/null <<'EOF'
Types: deb
URIs: https://mederel.github.io/beelot
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/beelot.asc
EOF
sudo apt update
sudo apt install beelot
